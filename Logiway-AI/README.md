# Logiway AI

Python 3.12 AI dataset utility for deterministic generation of synthetic Indonesian logistics scenarios. It generates synthetic data only; it does not train, fine-tune, or serve an AI model. Runtime Gemini integration remains in `Logiway-BE`.

## Safety and scope

Every generated row is labeled `synthetic_estimate` and states that it is not official or verified. Scenarios are generic operational estimates, not observations about real roads, legal requirements, or claims from Indonesian authorities. Users must verify current route, weather, facility, and authority information before operational use.

The regulation catalog contains one non-operational `pending` placeholder because no verified source branch or source reference was available during migration. Pending catalog records are excluded from generation. A record can be `verified` only when it has a source reference; none are included.

## Architecture

- `domain`: validated dataset, scenario, provenance, and regulation models
- `repositories`: storage and catalog contracts
- `infrastructure/repositories`: JSONL writer and JSON regulation catalog reader
- `services`: deterministic generator and generation use case
- `cli.py`: command-line composition root

## Install

```shell
python -m pip install -e ".[dev]"
```

## Generate

```shell
logiway-ai --count 260 --seed 2026 --output data/train_data.jsonl
```

Relative output paths resolve from the caller's current working directory. Parent directories are created automatically. Reusing the same count and seed produces byte-identical content.

Docker:

```shell
docker build -t logiway-ai .
docker run --rm -v "${PWD}/data:/output" logiway-ai
```

## Validate

```shell
ruff check .
mypy src
python -m compileall -q src
```

To validate a generated JSONL file with the package model:

```shell
python -c "import json; from pathlib import Path; p=Path('data/train_data.jsonl'); rows=[json.loads(x) for x in p.read_text(encoding='utf-8').splitlines()]; assert len(rows)==260; assert all(r['provenance']['kind']=='synthetic_estimate' and not r['provenance']['is_official'] and not r['provenance']['is_verified'] for r in rows); print(f'validated {len(rows)} rows')"
```

## Dataset provenance

`data/train_data.jsonl` is a deterministic replacement generated by this package with version `1.0.0`, count `260`, and seed `2026`. The legacy JSONL was reviewed but not copied because it mixed synthetic scenarios with unsupported official or verified wording. The replacement preserves useful Indonesian city, vehicle, time, congestion, weather, facility, vehicle-readiness, and night-safety scenario variety without carrying those claims forward.
